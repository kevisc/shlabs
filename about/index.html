About

Software for the rack, the DAW and the stage.

SHLabs is a small independent studio. The catalogue started with modules for VCV Rack. A second branch of VST3 and AU plugins and standalone apps is in beta. They run in Ableton Live, Logic, Bitwig and other hosts. The tools cover modulation, sequencing, generative sources, gate logic and stochastic processes. Many draw on analog computing, where a calculation was a physical process that you could see.

The catalogue

Two branches
Families

On the rack side, the catalogue has five families: Stochast, Mashina, Lucida, Rikoshet and Atmos. All of them are free. On the DAW side, the paid line covers synths, effects, mastering tools, MIDI generators and visuals. Both sides share one design language.

How it started

Background
In the first person

SHLabs is a one-person studio. I grew up near Zurich, Switzerland, and work as a data scientist. I have played synthesizers for as long as I can remember, and that led to modular.

The tools on this site began as things I built for my own jams, live shows and productions. One question kept coming up: what if the maths that usually stays inside code were something you could turn, patch and hear? The tools grew into families from there.

I now release them. I expand and test each one first. The VCV Rack modules came first, and the plugin line follows. New releases appear when they are ready.
