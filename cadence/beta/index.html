The Mac zip is 0.9.0: the Sampler's pads in Perform with a step sequencer, MATCH, tags, ratings and relink in the Collection, stems and grid-aware samples in the Sampler, a Composer with multi-select, a cycle and a tempo lane, plugins with a long look-ahead that no longer move the mix, mono and sidechain plugins, and true-peak meters. The release note has the whole list. The Windows installer is still 0.6.0 until our build minutes clear. Apple Silicon Macs need macOS 14 or newer. Intel Macs are not supported in this beta. Windows shows "Windows protected your PC" on first run: choose More info, then Run anyway. The SHLabs plugins are listed above one by one and per platform, so you can take only the ones you host in Cadence. The Mac plugin zips are fresh cuts for the launch: each carries its licence and third-party notices and passed an in-process smoke test; Glue is now Legato. Lacuna 0.2.0 and Schlagzeugs 0.2.0 are universal too. A Mac zip holds the AU and the VST3; a Windows zip holds the VST3 and a standalone exe. Each has its own install card. On the Mac, Cell, Contour, Legato (1.1.0, called Glue until 1.0.0; the Windows zip is still Glue 1.0.0), Spazio, Stesso and Tonnetz are universal builds and Phosphor 0.3.0 is Apple Silicon only. Nothing is code-signed for Windows, so the standalone exe asks once; a host loading the VST3 does not.

Bugs, impressions and questions to shlabs.contact@gmail.com. Most useful: what you did, what you expected, what happened, and the diagnostics file (CADENCE wordmark, About, Save diagnostics file).
