Cadence MIDI maps for DJ controllers

Controller profiles

A profile is a MIDI map for one controller. Download the file for yours, put it in Cadence's profiles folder, and pick it in the mapping dialog.

In Cadence, open MAP, then Profile, then Reveal profiles folder, and drop the file in. It then shows under Your profiles in the same menu. From Cadence 0.9.5 the menu also downloads them for you: Profile, then Download from shlabs.ch.

Not here yet

Some popular controllers publish no MIDI chart we could use: the Numark Mixtrack and Party Mix, the Hercules Inpulse MK2 models, the Denon DJ MC7000, SC LIVE 2 and Prime GO, the Rane ONE, the Reloop Buddy, the Novation Launch Control XL mk1 and mk2, the Korg nanoKONTROL2, and the Native Instruments Traktor Kontrol units. Learn maps any controller that sends MIDI, one control at a time. If you save a map from your own unit and send it to us, we will test it and add it here.
