Support

Contributions fund development time.

SHLabs is an independent studio. Development happens in evenings and at weekends. If a module is useful to you, a contribution helps pay for the next one and keeps the free modules free.

GitHub Sponsors

Recurring or one-off

Sponsor on GitHub with a monthly amount that you set, or send a one-off contribution. GitHub handles the payments, so you need only your existing GitHub account.

Other ways to help

Free
01 Spread the word

Tell people about it

Mention a module in a patch you share, on social media, or to a friend who racks. Word of mouth helps a small studio more than most things, and it costs nothing.

02 On GitHub

Open an issue

Bug reports, edge cases, and requests for new modules are all welcome on the SHLabs GitHub at github.com/shlabs-audio. Clear steps to reproduce a bug help most.
